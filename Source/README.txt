This directory is normally empty.

If you place a file here named exactly like a document ID plus ".txt",
for example:

    DOC000001.txt

its UTF-8 content will replace the built-in text for that document the
next time you run GenerateCorpus.py. See 00_Documentation/SourceDocumentsIndex.txt
in a generated corpus for the full list of document IDs, categories,
and titles.

This file itself is not a document override (its name doesn't match
the DOC###### pattern) and is ignored by the generator.
